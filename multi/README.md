# AI Model Arena

An AI model comparison and decision platform.

Users select multiple AI systems, submit one task, receive responses side-by-side, choose the preferred response, and continue working from that selected response.

## MVP

1. Select 2+ AI models
2. Enter one prompt/task
3. Send the same task to all selected models
4. Display responses side-by-side
5. Select a response
6. Continue/edit/copy/save the selected response

## Architecture

React + TailwindCSS → FastAPI → Model Adapter Layer → AI Providers
                                      ↓
                                   Database
